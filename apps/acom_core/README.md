# acom_core

Custom Frappe application for **PROJECT ACOM** (Phase 2 — Affiliate-first per ADR-0001).

## Modules (Phase 2)

- `ACOM Core` — `ACOM Settings` (Single DocType)
- `Affiliate Commerce` — `Affiliate Network`, `Affiliate Campaign`, `Product Highlight`, `Affiliate Product`, `Affiliate Click`, and public catalog / click recording services
- `Product Intelligence` — Pure `Decimal` contribution margin and reliability/product scoring logic
